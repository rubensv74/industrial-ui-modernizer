# Polish

Use only after the functional contract and layout are already correct.

Preserve behavior, information architecture, and established visual identity unless the user explicitly requests redesign.

Check in this order:

1. alignment and spacing consistency;
2. typography hierarchy and numeric scanning;
3. component/state consistency;
4. border, radius, elevation, and surface discipline;
5. icon sizing/alignment and label clarity;
6. hover/focus/pressed/disabled states;
7. long text and truncation behavior;
8. visual noise and redundant containers;
9. responsive edge cases;
10. screenshot comparison.

Do not solve a structural problem with cosmetic changes. If polish reveals a structural defect, report it and route back to shape/adapt/harden as appropriate.
