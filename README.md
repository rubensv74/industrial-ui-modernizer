# industrial-ui-modernizer

Reusable agent skill for premium modernization of industrial and enterprise UI.

The skill is defined in [SKILL.md](./SKILL.md).

Primary use:

```text
Use Industrial UI Modernizer on [SCREEN] and work autonomously until the next real gate.
```

The method preserves functional contracts and modernizes composition, hierarchy, spacing, depth, typography, semantic component variety and image integration. It explicitly prevents visual references from becoming permission to fabricate data or capabilities.
